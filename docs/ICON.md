# Release artwork

The release icon is an original mint pixel chat companion above a grass-topped dirt platform, with a gold sparkle on a dark navy background. It contains no lettering, official OpenAI mark, or copied Terraria artwork.

- Master: `assets/branding/terraria-chatgpt-master.png` (1254 × 1254)
- Mod list: `icon.png` (80 × 80)
- Workshop preview: `icon_workshop.png` (512 × 512)
- Export again: `powershell -ExecutionPolicy Bypass -File tools/CreateModIcons.ps1`

The original image was generated with the built-in OpenAI image-generation tool. The two publishing sizes are mechanical nearest-neighbor exports of the master. Both were visually inspected at their intended sizes. No image API key or third-party artwork was used.

## Generation prompt

Use case: logo-brand.
Asset type: square release icon for an independent Terraria ChatGPT tModLoader companion mod, used at 80x80 and 512x512.
Primary request: create one polished original pixel-art icon that instantly reads as a friendly intelligent chat companion in a pixel sandbox game.
Scene/backdrop: flat very dark midnight navy background filling the square.
Subject: one large, lovable mint-green pixel speech-bubble companion, two dark square eyes and a simple warm cheerful expression, hovering just above a small grass-topped dirt platform. One tiny warm golden four-point pixel sparkle beside the bubble.
Style/medium: authentic crisp chunky pixel art built of deliberate square blocks on a coarse 64x64 logical pixel grid, rendered up cleanly; carefully controlled limited palette and stepped silhouettes. The bubble is the dominant large symbol, with thick dark teal outline, bright mint front, a tiny soft green shaded side giving depth; white-mint highlights are pixel blocks.
Composition/framing: centered, bold simple readable silhouette, generous safe margin around all sides, subject occupies about 80 percent of square; platform compact beneath, no unnecessary details.
Lighting/mood: welcoming, capable, bright and readable on dark game menus.
Constraints: completely original artwork, no text, no letters, no OpenAI logo, no existing Terraria character or copied official game art, no watermark, no faux UI, no mockup, no blur, no gradients, no antialiased rounded vector edges, no collage. Deliver a single square icon only.
